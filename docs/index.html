웜홀 모니터
내 바탕화면에 웜홀을 뚫어요 🌀
구슬을 튕겨 컵에 골인! 화살은 창에 박히고, 볼링공은 창을 꾹 눌러요.
⬇ 맥용 다운로드
macOS 13 (Ventura) 이상 · 애플 실리콘 / 인텔 모두 지원 · 애플 공증 완료
  1. 받은 WormholeMonitor-mac.dmg 파일을 열어요.
  2. 웜홀 모니터 아이콘을 응용 프로그램 폴더로 끌어다 놓아요.
  3. 응용 프로그램(Launchpad)에서 웜홀 모니터를 실행하면 공구함이 떠요.
  4. 웜홀을 두 번 클릭해 한 쌍 놓고, 유리구슬을 골라 당겼다 놓으면 발사!
💡 창 밀어내기는 맥의 손쉬운 사용 권한이 필요해요 (공구함의 권한 켜기 → 웜홀 모니터 켜기).
실화면 녹화를 쓸 때만 화면 기록 권한을 물어봐요. 도트 영상은 권한 없이 저장돼요.
⬇ 윈도우용 다운로드
Windows 10 / 11 (64비트)
  1. 받은 WormholeMonitor-Setup.exe 를 실행해요.
  2. 파란 창 “Windows의 PC 보호”가 뜨면 추가 정보를 누르고 실행을 눌러요.
  3. 설치가 끝나면 웜홀 모니터 공구함이 열려요.
  4. 웜홀을 두 번 클릭해 한 쌍 놓고, 유리구슬을 골라 당겼다 놓으면 발사!
💡 “PC 보호” 창은 새로 나온 프로그램이라 뜨는 거예요. 추가 정보 → 실행을 누르면 설치돼요.
관리자 권한으로 실행된 창은 밀리지 않아요.
